# codex-cc-tuner

A Codex plugin for persistent, read-only second opinions from Claude Code.

Use it to stress-test a plan, review a complete branch diff, and ask follow-up questions in the
same Claude session. Threads are task-scoped and stored locally under `.codex/claude-threads/`.

## Install

Prerequisites: Git, Python 3, and an authenticated `claude` CLI on `PATH`.

```bash
codex plugin marketplace add clicktronix/codex-cc-tuner --ref main
codex plugin add codex-cc-tuner@codex-cc-tuner
```

Start a new Codex thread after installation, then invoke a skill explicitly:

```text
$claude-plan stress-test docs/plans/new-billing-flow.md
$claude-review review this branch against main for correctness and regressions
$claude-reply review-feat-billing re-evaluate after my fixes
$claude-thread status
$claude-thread new review-feat-billing
```

`$claude-plan` and `$claude-review` derive task-scoped thread names. Re-running either skill with
the same thread resumes the existing Claude session instead of starting over.

## Safety Boundary

The driver starts Claude with `--safe-mode`, `--permission-mode dontAsk`, no MCP configuration, and
only `Read`, `Glob`, and `Grep`. `dontAsk` denies anything outside that explicit allowlist instead of
opening a permission prompt. Review diffs are generated by the trusted wrapper and written to a
local ignored context file, so Claude does not need shell access. A before/after repository
fingerprint detects unexpected worktree mutation and fails the call.

The inspected repository content is sent through your configured Claude Code account. Local thread
IDs, prompts, results, and diagnostics remain in `.codex/claude-threads/` and are excluded through
the repository's local Git exclude file.

## Configuration

Environment variables:

| Variable | Default | Purpose |
| --- | --- | --- |
| `CODEX_CC_TUNER_CLAUDE_BIN` | `claude` | Claude Code executable |
| `CODEX_CC_TUNER_MODEL` | `sonnet` | Claude model or alias |
| `CODEX_CC_TUNER_MAX_BUDGET_USD` | `1.00` | Per-call print-mode budget cap |
| `CODEX_CC_TUNER_TARGET_REF` | auto-detected | Default review base ref |

Claude Code 2.1.214 no longer exposes the older `--max-turns` CLI flag, so the wrapper relies on the
current print-mode budget cap instead.
